# Reminders

NotallyX provides functionality to add reminders and persistent status bar notifications to your notes.

## Add Reminder to Note

From inside a Note:

1. Tap the 🔔 icon (or `...` in the bottom right corner -> **Reminders**).
2. Select a date and time for the reminder.
3. Select if the reminder should repeat and choose the repeat interval if applicable.
4. Tap **Save**.
5. When the scheduled date and time is reached, you will receive a notification alert for the note.

## Reminders Overview

To view and manage all active reminders:

1. From the Overview screen, tap the sidebar menu icon.
2. Tap **🔔 Reminders**.
3. View the list of notes with configured reminders.
4. Filter by upcoming or elapsed reminders.
5. Tap any note in the list to open and edit its reminder settings.

## Pin Note to Status Bar

You can also pin a note to your status bar to keep a persistent notification/reminder:

1. Tap the pinboard icon (or `...` in the bottom right corner -> **Pin to Status Bar**).
2. A persistent 📌 notification for the note will appear in your status bar.
