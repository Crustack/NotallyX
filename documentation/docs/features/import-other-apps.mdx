# Import from Other Apps

NotallyX allows you to easily import your existing notes from other popular note-taking applications as well as standard file formats.

## How to Import Notes

1. Open **Settings** in NotallyX.
2. Scroll to the **Backup** section and tap **Import notes from other app**.
3. Select the source app or file format you want to import from.
4. Follow the on-screen instructions to select your file or folder.

## Supported Import Sources

### 📱 Note-Taking Apps
- **[Google Keep](https://keep.google.com/)**: Export your notes via [Google Takeout](https://takeout.google.com/) as a ZIP file, then select the ZIP file in NotallyX.
- **[Evernote](https://evernote.com/)**: Export your notebooks as `.enex` files from Evernote, then select the ENEX file in NotallyX.
- **[Quillpad](https://quillpad.github.io/)**: Export a backup `.zip` file from Quillpad and select it in NotallyX.
- **[Notally](https://github.com/OmGodse/Notally)**: Import JSON notes or backups exported from the original Notally app.

### 📄 Standard File Formats
- **Plain Text Files (`.txt`)**: Import individual `.txt` files or an entire folder containing plain text files.
- **Markdown Files (`.md`)**: Import Markdown notes preserving headers, lists, and basic formatting.
- **JSON Files (`.json`)**: Import structured JSON note files or exported note collections.
