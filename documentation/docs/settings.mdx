# Settings

NotallyX offers a wide range of customization options to help you tailor the app to your preferences. This guide explains the various settings and customization features available.

<img src={require('/img/phoneScreenshots/8.png').default} width="32%" alt="Settings in NotallyX" />

## Appearance Settings

Customize how NotallyX looks and displays content:

- **View**: Toggle between Grid view and List view for your notes list.
- **Theme**: Choose between System default, Light, Dark, or Pure Dark (AMOLED) mode.
- **Date & Time Formats**: Customize date/time display formats separately for the Overview screen and inside Note views.
- **Text Size**: Adjust font sizes for notes and the overview list.
- **Show Search Bar in Top Bar**: Display a persistent search bar in the top app bar for quicker access.

## Behavior Settings

Tweak the app's behavior and default behaviors:

### Notes Sort Order
Choose how notes are ordered in the main view (by Creation Date, Modification Date, Title, or Color).

### Sort List Items
Choose how checked items in list notes are sorted (e.g. automatically move checked items to the bottom).

### Start View
Select which view or label is shown when you open the app (e.g. All Notes, Archive, Bin, or a specific Label).

### Default List-Note View Mode
Select the default view mode when opening a list note (Read mode, Edit mode, or Last used mode).

### Auto Save Note
Enable automatic saving of notes after a specified idle time without needing to manually tap save or exit.

### Auto Remove Deleted Notes
Set after how many days notes in the `Deleted` folder (Bin/Trash) are automatically removed permanently.

## Content Density Settings

Adjust how much information is previewed for each note in the overview:

- **Max Title**: Set maximum lines/characters for titles in the overview.
- **Max Items**: Set maximum items shown in task list previews.
- **Max Lines**: Set maximum body text lines displayed in note cards.
- **Max Labels**: Limit the number of label chips displayed on note cards.
- **Hide Labels / Images in Overview**: Optionally hide labels or image attachments in the main overview for a cleaner view.

## Security & Privacy Settings

Protect your notes and app data:

- **Biometric / PIN Lock**: Require biometric authentication (fingerprint, face) or device PIN whenever opening NotallyX.
- **Database Encryption (Experimental)**: Optionally encrypt the database file on disk via biometric credentials (using SQLCipher). *Note: This is an optional experimental feature and should be used with caution.*
- **Backup Password**: Set a password to encrypt exported backups using AES encryption.
- **Secure Flag**: Prevent screenshots, screen recordings, and hide app content previews in the Android recent apps switcher.

For more details, see [🛡️ Security and Privacy](./security-privacy.mdx).

## Backups & Auto-Backups

Keep your notes safe with automatic and manual backup options:

- **Backups Folder**: Select a local device folder or SAF WebDAV mount for storing backups.
- **Backup on Exit**: Automatically create a backup whenever you edit and exit a note.
- **Periodic Backups**: Schedule automatic background backups at regular day intervals and specify the maximum number of backup files to keep.
- **Export & Import Backup**: Manually export or restore your notes and attachments.

For more details, see [💾 Backups](./features/backups.mdx).

## Customizing Actions

You can customize which actions are immediately available in the edit screen's toolbar and bottom bar. Keep your most-used tools just a tap away.
For more details on how to use this feature, see [🛠️ Customizing Edit Actions](./features/edit-actions.mdx).

## Home Screen Widgets

NotallyX provides customizable widgets for your home screen:

### Adding a Widget

1. Long press on your home screen
2. Select "Widgets"
3. Find and select "NotallyX"
4. Configure the widget settings (choose list view, individual note, or specific label)

## Exporting and Importing Settings

To use the same app configuration across multiple devices:

1. Open the app settings
2. Scroll to the **Settings** section
3. Tap **Export settings** to save your current configuration to a JSON file
4. On another device, tap **Import settings** to apply the configuration

## Store Data in Public Folder

By default, NotallyX uses internal (app-private) storage to store its database and media attachments.
You can optionally choose to store app data in the public folder (`Android/media/com.philkes.notallyx`).
This is useful if you use synchronization tools like FolderSync or Syncthing to sync NotallyX data across devices.

To switch storage location:
1. Open Settings
2. Under the **Settings** section, tap **Store data in public folder**
3. Select whether to enable or disable public folder storage
