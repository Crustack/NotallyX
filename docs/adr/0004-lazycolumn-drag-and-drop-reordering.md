# Drag-and-Drop Checklist Item Reordering in EditListScreen

To enable drag-and-drop reordering for checklist items in `EditListScreen`, we decided to adapt `LazyColumnDragAndDropDemo.kt` state management (`DragDropState`) while delegating order-shifting and parent-child hierarchy resolution to the existing `ListManager.move()` and `ListManager.finishMove()` methods. Drag detection is attached exclusively to the `ChecklistItemRow` drag handle icon requiring a long press (`detectDragGesturesAfterLongPress`), preventing accidental drags during text editing or list scrolling. Drag-and-drop reordering is scoped strictly to active (unchecked) items, and instrumented tests (`EditListActivityTest.listItems()`) are configured to perform drag actions via the drag handle affordance.
